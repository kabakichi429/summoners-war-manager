## 4. アーティファクト厳選チェック

- [ ] **対ボス属性への与ダメUP（例: 対火属性与ダメUP）**：水属性・火属性問わず、すべてのアタッカーに装着したか
- [ ] **協力攻撃ダメージUP**：イカル・ラオーク・タークに追従するアタッカーに装着したか
- [ ] **単体スキルクリダメUP**：メインアタッカー・フィニッシャーに装着したか

## 5. 周回実行前チェックリスト

- [ ] 不利属性（ミスが発生する属性）のデバッファーが1体も混ざっていないか
- [ ] 前半デバッファーの速度上限が **170以下** に抑えられているか
- [ ] ブランディア（またはメイン削り役）と水イフ/バーレイグとの速度差が **約47以上** 確保されているか
- [ ] イカルを採用する場合、追加防御力が **+2430以上** に達しているか
- [ ] カリン・水イフ等の耐久カット調整が正しく反映されているか
- [ ] 闘志ルーンが全体のサポーター・置物枠に十分に積まれているか
