# ⚔️ サマナーズウォー 攻略管理システム (Summoners War Manager)

サマナーズウォー（Summoners War）のモンスター育成・ルーン構成・ギルド戦メモ、および**カイロスダンジョン全ダンジョン（深淵Hard等）の周回パーティ編成（全20編成）**を一括管理できるWebアプリケーションです。

外部サーバーやデータベースのセットアップは不要で、ブラウザだけで快適・安全に動作します（データはブラウザの LocalStorage に自動保存）。

---

## ✨ 主な機能

### 1. 🏰 カイロス周回パーティ データベース（全20編成）
現行環境（深淵Hard、鋼鉄、審判）の実績編成を初期プリセットとして網羅。手持ちモンスターやルーンの仕上がり度に合わせて選べるよう、各ダンジョンに複数のパターンを用意しています。

- **巨人ダンジョン (深淵Hard)** - 5編成
  - 高速ヒンメル＆ジュリー軸 (約32秒 / ルーン未完成時約50秒)
  - 【ジュリー不要・安定1分切り】アカムアミール＆ヒンメル軸 (約42秒)
  - ルシェン＆シャーマン軸 (F2P・リン/風ホム不要 / 約42秒)
  - 【テシャール不要】高速ジュリー＆リン軸 (約38秒)
  - アカムアミール＆リン軸 (調合・完全無課金F2P / 約48秒)
- **ドラゴンダンジョン (深淵Hard)** - 5編成
  - 高速リアム＆カイル軸 (代表的テンプレ / 約35秒)
  - ヴェラモス＆スペクトラ軸 (持続解除・安定F2P / 約50秒)
  - 【超高速】リアム＆ターク軸 (20秒台最速テンプレ / 約26秒)
  - 【リアム不要・星4/星3】カイル＆カーリー防御無視軸 (約38秒)
  - 【リアム不要・双子連撃】ブメチャク＆カイル軸 (約42秒)
- **死のダンジョン (深淵Hard)** - 4編成
  - 【最速】セレン＆アビゲイル軸 (最速テンプレ / 約30秒)
  - 高速多段＆シャーマン軸 (安定バランス型 / 約40秒)
  - 【双子連撃型】ブメチャク多段パ (約40秒)
  - 【完全無課金F2P】カリン＆ルーカシャ安定パ (星2・星3のみ / 約52秒)
- **精霊のダンジョン (深淵Hard)** - 3編成
  - 火属性ジーク速攻パ (クリ率半減無効化 / 約35秒)
  - ベレニス＆ライリー軸 (超安定・耐久クリバフ型 / 約48秒)
  - 【完全無課金F2P】ジーク＆カリン火属性パ (純4・純5不要 / 約55秒)
- **鋼鉄のダンジョン** - 5編成
  - 強化阻害安定パ (約45秒)
  - 【超高速】アグリオス＆テオン軸 (最速25秒テンプレ / 約25秒)
  - 【完全無課金F2P】ジンク＆クロー軸 (純5不要 / 約48秒)
  - 【ブランディア不要・道中切断】ルシェン＆クロー即殺軸 (約32秒)
  - 【ブランディア不要・高回転】ラオーク＆クロー協力攻撃軸 (約40秒)
- **審判のダンジョン** - 5編成
  - 高回転ヴェルデパ (手数重視 / 約50秒)
  - 【高速】クリーピー＆クロー軸 (速度バフ強奪型 / 約36秒)
  - ジュルタン＆カリン軸 (闇デコイ反射・超安定型 / 約58秒)
  - クロー導入型 (イカル入替・50秒切り / 約45秒)
  - セレン＆クロー加速型 (ヴィゴル速度バフ軸 / 約40秒)

### 2. ⚡ 視覚的な攻略フロー＆詳細管理
- **推奨行動順（Turn Order）**: `フリルレア ➔ テシャール ➔ テオン ➔ コナミヤ ➔ ルナ` のようにバフ・デバフの繋がりを視覚化。
- **速度同調・調整メモ**: 誰を最速にし、誰と何速差をつけるべきかを記録。
- **要件ステータス・ルーンセット**: 闘志ルーンの必要セット数、的中率基準、クリ率100%必須などの重要指標を網羅。
- **ターゲット指定**: ボス直撃、タワー優先などの設定方針を明記。

### 3. 📝 モンスター育成＆ギルド戦メモ
- モンスターごとに「推奨ルーン」「主な役割」「ギルド戦/占領戦メモ」「カイロスメモ」「一般メモ」を登録・編集可能。
- 属性（火・水・風・光・闇）ごとのカラーバッジやお気に入り（★）登録。

### 4. 🔍 クイックフィルター＆リアルタイム検索
- 属性ボタン（火・水・風・光・闇）やダンジョンボタン（巨人・ドラゴン・死ダン・精霊・鋼鉄・審判）によるワンタップ絞り込み。
- モンスター名や役割のリアルタイムインクリメンタルサーチ。

### 5. 💾 データ永続化（LocalStorage）
- 入力・編集したデータはお使いのブラウザの LocalStorage に自動保存されます。
- 初期プリセットへのリセットボタンも完備。

## 🚀 使い方

本システムは純粋なフロントエンド技術（HTML5, CSS3, JavaScript）のみで構築されているため、**環境構築やサーバー起動は不要**です。

### 1. リポジトリをクローンまたはダウンロード
```bash
git clone https://github.com/kabakichi429/summoners-war-manager.git
```

### 2. ブラウザで開く
ダウンロードしたフォルダ内の `index.html` をダブルクリック（または任意のブラウザにドラッグ＆ドロップ）するだけで起動します。
