異次元レイド 攻略要件＆ステータス基準

📜 異次元レイドの完全仕様と戦闘フロー

【コンテンツ概要】 異次元レイドは、古代ルーンの強化素材である「古代の練磨石」「古代の宝石」を獲得するための最高峰1人用レイド（全5段階）です。 1回の入場につき次元ホールエネルギーを1個消費（連続バトル対応）。 ボスは1週間ごとに各次元（カルザン ➔ エルニア ➔ ルメール ➔ カルデルン ➔ サクリファス 等）を巡回・移動します。 【チーム編成の絶対ルール】 ・全3フェーズ連続戦闘で、各フェーズごとに「5体」のモンスターを編成（5体×3デッキ＝合計15体）。 ・同じモンスターを複数のフェーズで重複して編成することは不可（15体すべて異なるモンスター）。 ・各フェーズごとに個別のリーダースキルを設定可能（※効果はそのフェーズの5体のみに適用）。 ・Phase 2・Phase 3の条件は固定されているため、P2・P3デッキを強固に固定しておき、ボスの週替わり移動に合わせてP1のデッキのみを調整・特化させるのがセオリーです。

🦅 Phase 1：週替わり異次元制限ボス戦 (5体編成)

【フェーズの仕組みと条件】 ・ボスが滞在している次元の入場ルールがそのまま適用されます。 - カルザン週：純正★4以下のみ編成可能 - エルニア週：同一属性のみ編成可能（風属性統一など） - ルメール週：純正星ランク合計20以下 - カルデルン週：全4タイプ（攻撃・防御・体力・サポート）を各1体以上編成 ・ボスのHPを削り切るとボスが逃亡し、Phase 2へ自動移行します。 【編成の要点（カルザン週の例）】 ・ヴェルデハイル(L)のゲージ回し＋フランの免疫・攻撃バフ・回復。 ・二次覚醒ラオーク（協力攻撃）と二次覚醒クロー（弱化特効「傷口ほじくり返し」）でボスのHPを一気に削り落とす。 ・ローレンやカリンを添えることで、盾割り・攻撃弱化（剣折り）・回復阻害を初手から切らさないことが安定の秘訣。 【推奨ステータス基準】 ・ヴェルデハイル: 暴走+反撃 (クリ率100%必須、速度+80以上、体力+15000以上) ・フラン: 迅速+反撃/元気 (速度+110以上、効果抵抗50%以上、体力+18000以上) ・二次覚醒クロー: 激怒+刃 (攻撃+1400以上、クリ率85%以上、クリダメ180%以上) ・二次覚醒ラオーク: 暴走+刃 (攻撃+1300以上、クリ率85%以上、クリダメ160%以上) ・ローレン / カリン: 迅速+集中 / 反撃+闘志 (速度+90以上、的中45%以上、高耐久)

🌲 Phase 2：繭＆ミニオン殲滅戦 (5体編成・固定条件)

【フェーズの仕組みと最重要ギミック】 ・逃亡したボスが中央の「繭（コクーン）」に籠もり、HPを回復しようとします。 ・同時にボスを守るミニオン（手下モンスター群）が出現。画面上部にボスのHP回復ゲージが表示されます。 ・【超重要】ミニオンを素早く全滅させるほど、ボスの回復量を低く抑えられ、Phase 3で覚醒・進化したボスの攻撃力上昇を大幅にカットできます！ 【編成の要点】 ・ミニオンを1ターンで一掃できる「全体攻撃（AoE）アタッカー」が極めて有効。 ・風属性軸ならルシェン（切断の魔法）＋アカムアミール（全体スタン＆弱化比例大砲）＋フレスベルグ（攻撃/速度バフ）＋ライリー/タラニス。 ・水属性/配布軸ならシグマルス（全体凍結大砲）＋コナミヤ＋メガン＋ヴィゴル＋バナード。 ・手持ちに応じてプロム(2A)、リンダ(2A)、ジーク等の高回転・全体攻撃持ちを組み込み、回復ゲージが溜まりきる前に殲滅します。 【推奨ステータス基準】 ・ルシェン / アミール / シグマルス: 激怒+刃 (攻撃+1300以上、クリ率85%以上、クリダメ170%以上) ・ライリー / コナミヤ: 暴走/迅速+意志 (速度+100以上、体力+24000以上) ・タラニス: 守護+守護+意志 (速度+70以上、防御+1400以上、体力+18000以上)

💀 Phase 3：覚醒ボス決戦・シールド破壊 (5体編成・固定条件)

【フェーズの仕組みと「次元歪曲」シールド対策】 ・最終進化した覚醒ボスとの決戦（5体パーティ）。 ・ボスは「次元歪曲（Dimension Distortion）」という強力な被ダメージ大幅軽減シールドを発動します。 ・【最重要特効スキル】：「ダメージ減少効果を無視」するスキルを持つモンスターを編成することで、ボスのシールドを貫通して特大ダメージを与え、瞬時にシールドを粉砕できます！ 【推奨モンスターと役割】 ① アイアン (火リビングアーマー 2A): 【無課金・必須級特効】 スキルやパッシブで「ダメージ減少効果無視」を持ち、ボスのシールドを一撃で貫通破壊する最重要キャラ。 ② カルカノ (火スナイパー): パッシブの確定盾割りに加え、「ダメージ減少効果無視」の超精密射撃でボスのシールドを粉砕。 ③ ヒンメル: ボス特攻（ボス戦与ダメージ+100%＆味方被ダメージ20%軽減）で圧倒的な削り速度と安全性を提供。 ④ ディアス / ダリオン: 味方の被ダメージを15〜20%常時カットするパッシブ＋盾割り。ヒンメルと合わせると最大35%被ダメカット！ ⑤ ヴェラモス / デルフォイ / ルル(2A): ボスの全体デバフを毎ターン自動解除＆免疫で無力化。 ⑥ ヴィゴル(2A) / ベラデオン(2A): 3連盾割り、全体速度バフ、回復、ゲージ上げでパーティの回転と火力を底上げ。 【推奨ステータス基準】 ・アイアン(2A): 守護+守護+意志 (防御/クリダメ/防御 または 防御/防御/体力、防御+1400以上) ・カルカノ: 猛攻+意志 (攻撃+1300以上、クリ率70%以上、クリダメ160%以上) ・ヒンメル: 激怒+刃 (速度+80以上、クリ率85%以上、クリダメ200%以上) ・ヴェラモス / デルフォイ / ルル(2A): 迅速/暴走+意志 (速度+90以上、体力+22000以上、効果抵抗50%以上) ・ヴィゴル(2A): 迅速+元気 (速度+115以上、体力+28000以上)
